# Seedance 2.0 / 2.5 Prompt Rewriter Skill

一个面向 **Doubao Seedance 2.0 与 Seedance 2.5** 的视频提示词导演与改写 Skill。

它不是简单的提示词润色器：先判断视频任务类型和输入完整度，再补齐真正影响成片的变量；在输出最终 Prompt 之前，强制确认用户使用 Seedance 2.0 还是 2.5；最后只按已确认版本的能力边界生成可直接使用的提示词。

> 本项目为社区整理的非官方 Skill，不隶属于字节跳动、火山引擎或 Seed 团队。

## 核心行为

### 版本确认是最终输出前的硬性闸门

当创作信息已经足够，或用户已经补齐此前追问的信息后，Skill 必须先询问：

> 这次要按哪个模型编写：Seedance 2.0 还是 Seedance 2.5？两者的时长、时间戳、参考与编辑能力不同，我会按你确认的版本输出。

在用户明确回复 `2.0` 或 `2.5` 之前，不输出最终 Prompt、完整提示词代码块或可直接复制的版本化模板。用户说“你决定”“别问”时，也只能跳过非关键创作变量，不能跳过版本确认。

## 使用

将整个技能目录放入支持 Agent Skills / Skills 文件格式的项目或 Agent 环境中，至少保留 `SKILL.md` 和 `references/SEEDANCE_25_RULES.md`，这样 2.5 分支的规则才能被读取。

### 两个版本保留独立规则

| 版本 | 适用规则 | 时间控制 | 能力边界 |
| --- | --- | --- | --- |
| Seedance 2.0 | 原有 2.0 任务类型、素材职责、镜头语言、编辑/延长逻辑 | 时间码可选，主要作为叙事顺序与节奏描述 | 按约 15 秒级单次生成规划；不套用 2.5 专属能力 |
| Seedance 2.5 | 读取 [`references/SEEDANCE_25_RULES.md`](references/SEEDANCE_25_RULES.md) | 按需使用时间戳/时间区间控制故事、视角、运镜、动作和节奏 | 单次最长 30 秒，支持多轮延长、升级多模态参考、白模/绿幕/定向编辑 |

2.5 的时间戳是时间段级的生成或编辑目标，不是 Premiere/剪映意义上的帧级精确剪辑指令。它不保证动作一定在 `4.000s` 开始、`6.000s` 结束；真正需要逐帧对齐时，应在生成后使用专业剪辑工具复核。

## 能力范围

- 自动判断：文生视频 / 多模态参考 / 视频编辑 / 视频延长 / 组合任务
- 信息不足时只追问少量、真正影响结果的变量
- 用户回复“你决定”后自动补全非关键变量
- 明确图片、视频、音频以及白模各自承担的参考职责
- 处理单镜头、多镜头、广告节奏、对白、旁白、BGM 和音效
- 检查主体身份、道具归属、动作因果、运镜冲突、时间密度和素材职责
- 优先使用可观察、可拍摄、可执行的导演语言，避免无效形容词堆砌
- 保留用户原始故事、人物关系、产品卖点、对白和结尾状态

## 工作流

```text
解析需求
  → 判断任务类型
  → 检查输入完整度
  → 必要时追问创作变量
  → 确认 Seedance 2.0 / 2.5
  → 进入对应版本分支
  → 做冲突与能力边界检查
  → 输出一个版本的最终 Prompt
```

如果用户的输入过于简单，先补齐主体、场景、动作、镜头、风格或时长等关键变量；信息足够后，不得默认选择版本。确认版本后只输出用户选中的版本，不同时混用 2.0 和 2.5 规则。

## Seedance 2.0 分支

2.0 分支保持原有行为：

- 文生视频使用“主体 + 场景 + 动作/事件 + 镜头 + 视觉风格/光影 + 音频/对白 + 必要约束”；
- 多模态任务逐一说明图片、视频、音频分别参考人物、产品、动作、运镜、节奏或音色什么内容；
- 编辑任务明确“编辑哪个视频、改什么、保留什么”，不误写成“参考视频生成”；
- 延长任务明确向前/向后、承接边界状态、后续动作、镜头和声音如何连续；
- 时间码不是默认必需项；用户没有指定按秒控制时，使用镜头顺序或自然语言描述；
- 明显超过约 15 秒或包含多个硬场景断点时，拆成片段或使用视频延长；
- 不使用 2.5 的 30 秒长叙事、时间戳定向编辑、白模控制或绿幕编辑表述。

## Seedance 2.5 分支

2.5 分支在通用导演规则之上增加：

- 30 秒内组织铺垫、推进、转折和收尾等逻辑关联的长叙事；
- 单次最多 30 张图片、10 段视频、10 段音频作为参考；
- 用白模控制空间结构、人物姿态、运动轨迹、机位、景别和调度，再用图片等素材指定外观、材质、光照、色彩或氛围；
- 用时间区间绑定某段故事、视角、景别、运镜、动作、表演、声音或节奏；
- 对生成后指定片段中的角色、动作、声音或剧情做定向编辑，并明确片段前后连续性；
- 绿幕编辑、视角/运镜编辑、参考编辑等高级任务必须明确编辑对象和保留内容；
- 复杂运动与多主体交互仍需保留真实感和稳定性的边界说明，不做绝对效果承诺。

### 时间戳写法

只有在用户提供时间码、明确要求按秒规划/卡点，或 2.5 定向编辑需要定位片段时才使用时间范围。推荐：

```text
0–4s：起始状态 → 一个主要动作或运镜 → 结束状态
4–8s：承接上一段 → 一个主要动作或运镜 → 结束状态
8–12s：完成收束 → 最终画面状态
```

从零设计时优先使用连续、非重叠并覆盖目标时长的区间；如果用户已经给出不连续区间或引用官方示例，不擅自修改数字。每个时间段不要塞入多个无因果关系的完整动作。

完整规则、编辑/延长模板和白模示例见 [`references/SEEDANCE_25_RULES.md`](references/SEEDANCE_25_RULES.md)。

## 典型用法

输入：

> 12 秒横屏，一位陶艺师在采光工作室制作蓝釉花瓶：镜头从转动的陶土近景开始，跟随双手塑形，最后推近到完成的花瓶，安静纪录片质感。

如果信息已经足够，Skill 会先确认 2.0 或 2.5，而不是直接默认版本。用户确认后，再按对应分支输出：2.0 使用连续动作与镜头顺序；2.5 只有在需要按秒控制时，才会拆成 `0–3s` 陶土起形、`3–8s` 双手塑形、`8–12s` 成品展示等时间段，并明确这些是时间段级目标，不是帧级剪辑指令。
