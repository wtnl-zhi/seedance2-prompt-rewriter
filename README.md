# Seedance 2.0 Prompt Rewriter Skill

一个面向 **Doubao Seedance 2.0** 的视频提示词导演与改写 Skill。

它不是简单的“提示词润色器”，而是先判断任务类型和输入完整度，再决定是直接转写还是追问关键缺失信息，最后输出更适合 Seedance 2.0 的可执行视频提示词。

> 本项目为社区整理的非官方 Skill，不隶属于字节跳动、火山引擎或 Seed 团队。

## 核心能力

- 自动判断：文生视频 / 多模态参考 / 视频编辑 / 视频延长 / 组合任务
- 输入过于简单时，不盲目扩写，先补齐真正影响成片的关键变量
- 用户可回复“你决定”跳过追问，由 Skill 自动补全
- 明确图片、视频、音频各自的参考职责
- 处理单镜头、多镜头、时间码、广告节奏、对白、音效
- 检查动作、运镜、时序和素材职责冲突
- 避免无效的形容词堆砌，优先使用可观察、可执行的导演语言
- 面向 Seedance 2.0 的多模态参考、编辑、延长与 15 秒级多镜头生成逻辑

## 使用

把 `SKILL.md` 放入支持 Agent Skills / Skills 文件格式的项目或 Agent 环境中即可。

典型输入：

> 10 秒，一个印尼男人肚子痛坐在卫生间，另一个朋友拿着产品冲进来救他，搞笑广告。

Skill 会先判断现有信息是否足够。如果关键变量不足，会只追问对成片影响最大的几个问题；信息足够后输出可直接用于 Seedance 2.0 的 Prompt。

## 官方依据

本 Skill 的规则主要依据火山方舟官方《Doubao Seedance 2.0 系列提示词指南》与《Doubao Seedance 2.0 系列教程》，并结合字节跳动 Seed 团队的 Seedance 2.0 官方发布说明整理。

官方原文入口、更新时间和用途说明见：[`references/OFFICIAL_GUIDES.md`](references/OFFICIAL_GUIDES.md)。

出于版权与版本更新考虑，本仓库**不镜像官方文档全文**；请通过官方链接阅读最新原文。

## 测试

`TESTS.md` 包含以下典型验收场景：

- 极简输入应触发追问
- 信息足够时应直接转写
- 多模态素材职责不清时应追问
- 视频编辑不能误写成“参考生成”
- 视频延长必须承接原视频结尾状态
- 用户明确“不追问”时应自动补全
