# Official Seedance Guides

> 说明：这里不镜像火山引擎 / Seed 官方文档全文。原因有两个：
> 1. 官方文档受版权保护；
> 2. 官方指南会持续更新，直接链接官方页面更能保证版本新鲜度。

> 因此，本文件只保留官方原文入口、用途和简要说明。

## 1. Doubao Seedance 2.0 系列提示词指南

官方原文：
https://www.volcengine.com/docs/82379/2222480?lang=zh

用途：
- Seedance 2.0 提示词设计的首要依据
- 多模态参考任务的提示词表达
- 视频编辑、延长等任务的指令组织
- 主体、动作、镜头、时序与素材职责的描述方式

本项目中的 `SKILL.md` 主要从这篇官方指南中抽象出可执行的 Agent 规则，包括：
- 先判断任务类型，再写提示词
- 明确每个图片 / 视频 / 音频素材分别负责参考什么
- 编辑任务应直接表达“编辑哪个视频、改什么、保留什么”
- 延长任务应明确承接原视频状态以及后续动作
- 优先使用可观察、可执行的描述，而不是单纯堆叠抽象风格词

## 规则优先级

当多个来源出现表述差异时，本项目按以下优先级处理：

1. Seedance 2.5 官方模型页与最新官方发布说明（仅用于已确认的 2.5 分支）
2. 当前版本 Seedance 2.0 官方提示词指南（仅用于已确认的 2.0 分支）
3. 当前版本 Seedance 2.0 官方教程（仅用于已确认的 2.0 分支）
4. Seed 团队 Seedance 2.0 官方发布信息
5. Seedance 1.5 Pro 官方指南
6. Seedance 1.0 官方指南
7. 社区教程、经验贴、二次整理文章

社区内容只能作为经验补充，不能覆盖官方规则。

## 建议维护方式

每次准备大版本更新 `SKILL.md` 前：

1. 重新打开对应版本的官方指南、模型页和发布说明。
2. 检查官方页面的更新时间和能力说明，尤其是 2.5 的时长、参考上限、时间戳和编辑边界。
3. 对比 `SKILL.md` 与 `references/SEEDANCE_25_RULES.md` 中的版本路由、任务分类、素材引用、编辑、延长和时间戳逻辑。
4. 若官方规则改变，优先修改 Skill，再更新测试用例和 README。
5. 在提交记录中说明对应的官方文档版本 / 检查日期。
